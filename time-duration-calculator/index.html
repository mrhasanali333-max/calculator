About duration

When the end time is earlier than the start time, the calculator treats it as an overnight period.

How to Use This Calculator

  1. Enter start and end times.
  2. Select Calculate.
  3. Review hours, minutes, and total minutes.

Formula and Method

Example

10:30 PM to 6:30 AM is an eight-hour overnight duration.

FAQ

Does it support overnight shifts?

Yes. An earlier end time is interpreted as the following day.
