Security Policy

Fast Calculator is committed to a safe, trustworthy experience for everyone who uses our tools and services.

About Fast Calculator

Fast Calculator is a free online calculator website created by Hasan Ali.

Website: https://fastcalculator.website/

Supported versions

We support the current live website and do not provide support for older versions.

Reporting a vulnerability

If you discover a security vulnerability or security issue on Fast Calculator, please report it responsibly through:

https://fastcalculator.website/contact.html

Please include:

  • A clear description of the issue.
  • The affected page or feature.
  • Steps to reproduce the issue, if possible.
  • Screenshots or helpful technical details.

Responsible disclosure

  • Do not access, modify, download, or delete other users' information.
  • Do not perform destructive testing, spam, denial-of-service attacks, or any activity that could interrupt the website.

Website security

We work to improve website security through appropriate technical and administrative measures, including:

  • HTTPS encryption.
  • Secure website configuration.
  • Updates to website code and dependencies.
  • Appropriate protection of account information.
  • Review and correction of security issues when identified.

Third-party services

Fast Calculator may use third-party services such as hosting, authentication, analytics, or advertising providers. Their security and privacy practices are governed by their own policies.

Response

We will review security reports and take appropriate action where possible. Response times may vary depending on the severity and complexity of the issue.

Contact

For security-related questions, visit:

https://fastcalculator.website/contact.html
